# GoHighLevel Dental Funnel Academy

A self-contained learning website for practicing a dental clinic lead-generation funnel in GoHighLevel.

## Project structure

- `index.html` — lesson content and page structure
- `css/styles.css` — responsive layout and visual styling
- `js/app.js` — lesson navigation, progress tracking, checklists and quiz

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the complete contents of this folder (keep the `css` and `js` folders).
3. Open repository **Settings → Pages**.
4. Select deployment from the `main` branch and `/ (root)`, then save.
5. Open the Pages URL GitHub provides.

## Important

The GHL screens are illustrative training mockups, not an exact reproduction and not connected to a live GoHighLevel account. Use fictional test contacts. Confirm the clinic's privacy, consent, messaging, availability and healthcare requirements before deploying a real funnel.
